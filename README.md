# Karnataka Public School (CBSE) - Landing Website

Official landing website for Karnataka Public School (KPS), Bengaluru. Managed by Karnataka Educational Trust (KET).
- **CBSE Affiliation:** #830385 (School Code: 45312)
- **Grades:** Pre-KG to Class 10
- **Academic Year:** 2027–28 Admissions
- **Campus:** 22/1, Chokkanahalli, Hegde Nagar Main Road, Yelahanka Hobli, Bengaluru, Karnataka – 560064

## Tech Stack
- Next.js (App Router, Turbopack)
- React 19, TypeScript
- Vanilla CSS design tokens & bespoke responsive styling

## Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the site.

## Build for Production
```bash
npm run build
npm start
```
