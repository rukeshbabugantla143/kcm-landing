# Karnataka College of Management (KCM) - Landing Website

Official landing website for Karnataka College of Management (KCM), Bangalore. Established under Karnataka Education Trust (KET Estd. 2003).

- **Approvals & Affiliations:** Approved by AICTE, New Delhi | Affiliated to Bengaluru City University | Recognized by UGC & Govt. of Karnataka
- **Programs:** Master of Business Administration (MBA - Marketing, Finance, HR, Business Analytics)
- **Academic Year:** Admissions 2026–2028
- **Placement Highlights:** 100% Placement Support | ₹12.36 LPA Highest Package | ₹7.5 LPA Average Package | 150+ Corporate Partners
- **Campus Address:** #33/2, Thirumenahalli, Hegde Nagar Main Rd, Yelahanka, Bengaluru, Karnataka – 560064
- **Official Website:** [https://kcm.org.in/](https://kcm.org.in/)

## Tech Stack
- Next.js (App Router, Turbopack)
- React 19, TypeScript
- Custom CSS design tokens, responsive bento grids & micro-interactions

## Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the site.

## Build for Production
```bash
npm run build
npm start
```
